# 界面截图

本目录用于存放 DeskFlow 的界面截图，供 README 与项目展示引用。

## 文件清单

| 文件名 | 内容 |
| --- | --- |
| `01_main_interface.png` | 主界面：画布 + 便签 + 抽屉式侧栏 |
| `02_notes.png` | 便签（`Ctrl+N`），配色与字号 |
| `03_mindmap.png` | 思维导图节点与连线（`Ctrl+M`） |
| `04_tasks_calendar.png` | 任务清单与日历（侧栏） |
| `05_search.png` | 全局搜索（`Ctrl+F`） |

命名沿用 `NN_功能名.png`，根目录 README 按此相对路径引用。

## 截图要求

- 分辨率不低于 1280×800，建议 1920×1080
- 使用默认主题，界面中不要出现真实个人数据
- PNG 格式，单张不超过 2 MB
